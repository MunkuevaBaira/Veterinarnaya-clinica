# ВетКлиника 🐾

Учебный проект сайта ветеринарной клиники, выполненный в рамках задания. Сайт включает в себя современный дизайн, адаптивную верстку, интерактивные элементы и отправку заявок на почту.

## 🚀 Ссылка на живой сайт (Netlify)
Посмотреть работающий сайт можно по ссылке:
👉 **(https://veterinarnaya-clinica.netlify.app)** 
## 🛠️ Стек технологий
* **HTML5** — семантическая верстка.
* **CSS3** — Flexbox, Grid, CSS-переменные, адаптивность, анимации.
* **JavaScript (Vanilla)** — работа с DOM, события, валидация, LocalStorage, Intersection Observer.

## ✨ Реализованный функционал

### Основные секции:
* **Главный экран** с призывом к действию.
* **Услуги** — карточки с кнопками записи (при клике на кнопку услуга автоматически подставляется в форму записи, и страница плавно прокручивается к ней).
* **Врачи** — карточки специалистов с возможностью открыть модальное окно с подробным описанием.
* **Отзывы** — слайдер с отзывами клиентов (написан на чистом JavaScript, без сторонних библиотек).
* **Форма записи** — принимает имя, телефон и дату. Валидация полей проверяет, чтобы дата не была в прошлом, а телефон соответствовал формату.

### Выполненные дополнительные задания (10 шт.):
1. **Кнопка «Наверх»** — появляется при прокрутке страницы и плавно возвращает в начало.
2. **Плавная прокрутка** — реализована через CSS `scroll-behavior: smooth`.
3. **Анимация появления карточек** — при прокрутке карточки плавно выезжают (через `IntersectionObserver`).
4. **Использование LocalStorage** — сохраняется выбранный язык сайта и имя пользователя в форме записи.
5. **Страница 404** — создан отдельный файл `404.html` для обработки несуществующих страниц.
6. **Отправка формы на почту** — данные отправляются прямо на указанный email через сервис FormSubmit.co (без перезагрузки страницы).
7. **Переключение языка (RU/EN)** — кнопка в шапке переводит весь текст сайта (с сохранением выбора).
8. **Живой поиск** — поле поиска фильтрует карточки услуг в реальном времени.
9. **Слайдер без библиотек** — карусель отзывов, написанная на чистом JS.
10. **Модальное окно** — при клике на «Подробнее» у врача открывается всплывающее окно с его характеристиками.

## 💻 Инструкция по локальному запуску
1. Склонируйте репозиторий или скачайте файлы проекта.
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari).
   *(Примечание: для проверки работы формы отправки сообщений сайт должен быть размещен на реальном сервере, например, на Netlify или через Live Server в VS Code).*

## 🌐 Процесс деплоя
Исходный код проекта хранится на GitHub. Публикация и автоматическое обновление сайта настроены через платформу **Netlify**. Любые изменения, внесенные в ветку `main`, моментально отражаются на живом сайте.
